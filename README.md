## Publish your own blog posts
Use GitHub’s built-in editor (Add file → Create new file). Name the file `_posts/YYYY-MM-DD-your-title.md` and start it with:

```yaml
---
layout: post
title: "Your title"
date: 2026-10-14
---
```

Write below that header using Markdown. Choose Commit changes to publish. The blog index and sitemap update automatically. Only you and collaborators you authorize can edit. Draft in `_drafts/` to keep a post off the website, but remember this repository is public: never store private drafts or personal information here.
