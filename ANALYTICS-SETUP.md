# Website visitor statistics
Status: prepared, not activated. No data is being collected by this integration.

## Activate
1. Sam manually registers at https://www.goatcounter.com/signup and verifies the email.
2. Set the site domain to sgandrushenry-oss.github.io. Keep the statistics dashboard private.
3. Set timezone to America/Denver. Leave individual pageview collection disabled.
4. Supply only the dashboard URL or public count endpoint; no password or API secret is needed in the website.
5. Set endpoint in analytics.js to the verified https://ACCOUNT.goatcounter.com/count endpoint.
6. Before publishing, add a brief visitor analytics disclosure linking to https://www.goatcounter.com/help/privacy in the site's footer and blog layout.
7. Merge this branch and confirm a test view appears in the private dashboard. Exclude Sam's browser using GoatCounter's own ignore-browser setting.

## Each week's review
Select the previous complete Monday–Sunday week and compare it with the preceding week:
- Total visits/pageviews as labelled by GoatCounter (not interchangeable).
- Most visited blog posts, teaching philosophy, galleries, and CV page.
- Referring websites.
- Broad country and device/browser totals, if enabled.
- Export CSV for a lasting record if useful.

These counts are estimates, not identified people. They do not prove reading completion. Ad blockers and privacy preferences can reduce counts. The site integration honours Do Not Track and Global Privacy Control, omits URL queries/fragments, and reduces referral URLs to the originating site. It does not record form contents or add session recordings. Collection begins only after activation; earlier traffic cannot be reconstructed by this integration. Weekly email delivery has not been configured.
